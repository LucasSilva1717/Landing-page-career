# 🚀 Portfólio Profissional (Currículo Web) - Nathan Lucas

## 📌 Sobre o Projeto
Este projeto é uma **Landing Page de Portfólio e Currículo Web** desenvolvida para centralizar e apresentar minha trajetória profissional, habilidades técnicas e projetos realizados. O site foi projetado com uma identidade visual moderna (Dark Mode com detalhes em laranja e elementos tecnológicos) para servir como meu principal cartão de visitas digital para recrutadores e conexões de mercado.

---

## 🏠 Estrutura e Funcionalidades do Site

O site é composto por uma página única (*Single Page Application* / *Landing Page*) dividida nas seguintes seções estratégicas:

* **🏠 Hero Section (Home)**: Tela de boas-vindas com uma apresentação inicial impactante como Desenvolvedor Full-Stack, destaque para as principais linguagens core (Java, JS, TS) e um botão de chamada para ação (CTA) para visualização do currículo.
* **💻 Projetos Realizados**: Galeria organizada em formato de *cards* dividida entre APIs Rest (Back-end) e Sites Completos/Home Pages (Front-end), detalhando as tecnologias específicas de cada solução.
* **🎯 Foco Técnico**: Seção que consolida meus três pilares principais de atuação profissional: Desenvolvimento Backend, Desenvolvimento Frontend e Persistência/Integração de Dados.
* **🧠 Conhecimento**: Listagem transparente do meu tempo de estudo e nível de experiência com as principais tecnologias do mercado, acompanhada por uma ilustração isométrica personalizada.
* **👤 Sobre**: Um resumo aprofundado da minha história, destacando minha base em engenharia de software iniciada em 2017, minha pausa para servir ao Exército Brasileiro (onde consolidei disciplina e resiliência) e meus objetivos atuais, como a certificação *AWS Certified Developer Associate*.
* **📞 Contato & Redes Sociais**: Central de comunicação que disponibiliza canais de contato direto (WhatsApp, E-mail profissional e Localização) e links para conexões em redes externas (LinkedIn, GitHub e Instagram).

---

## 🛠️ Tecnologias Utilizadas

### 💻 Front-end
* **HTML5** & **CSS3** - Estruturação semântica e layouts modernos.
* **Tailwind CSS** - Estilização rápida, utilitária e totalmente responsiva.
* **JavaScript** & **TypeScript** - Lógica de programação e tipagem estática para robustez.
* **React** - Criação de interfaces dinâmicas e componentizadas.

### ⚙️ Back-end & Persistência
* **Java** & **Spring Boot** (Spring Security, Data, Web) - Construção de aplicações robustas server-side e APIs RESTful.
* **Node.js** & **Express** - Criação de serviços escaláveis em ambiente Javascript.
* **Bancos de Dados**: PostgreSQL, MySQL (Relacionais) e MongoDB (Não-relacional).

### 🚀 Infraestrutura & DevOps
* **Docker** - Conteinerização e isolamento de ambientes.
* **RabbitMQ** - Mensageria e arquitetura orientada a eventos.
* **AWS (Amazon Web Services)** - Serviços de nuvem para deploy e escalabilidade.
* **Git & GitHub** - Controle de versionamento de código.
* **Linux** - Administração de ambientes de servidor para deploy.

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
Antes de começar, você vai precisar ter instalado em sua máquina o [Node.js](https://nodejs.org).

### Passo a Passo
1. Clone este repositório para sua máquina local:
   ```bash
   git clone https://github.com
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd seu-repositorio
   ```
3. Instale as dependências do projeto:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Abra o navegador no endereço indicado no terminal (geralmente `http://localhost:5173` ou `http://localhost:3000`).
